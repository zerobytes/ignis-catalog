# Ancestral tree collection

First-party procedural assets by Guilherme Oliveira / Zerobytes, CC BY 4.0.

The compact species profile creates additional individuals. `authoring.json` pins
the approved original snapshots by SHA-256, their palettes and placement/environment
settings. Each versioned download additionally carries the complete exact
`.ignis-botany` organ graph, the full native scene and fixed materials, and portable
GLB geometry. The original white tree is an authored snapshot rather than a
claim that regenerating the species profile reproduces that snapshot byte-for-byte.

Moss is an independent prepared layer. Place/rotate/scale trees first and prepare
moss explicitly before exporting the world. The saved static scene renders it
without regenerating it during gameplay. Growth or structural edits require
preparation again. Native editing requires botanical recipe 34 / scene 138.

Portable GLB and browser meshes use representative PBR colors. The native scene
contains full bark/moss textures, material domains and border shading. Browser
previews also reduce tessellation and moss surface resolution. This difference
is intentional and must remain visible in the portal/package description.

No reference photos, vendor meshes or extracted game content are included.
These are authored fantasy trees, not biologically calibrated species.
